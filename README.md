## Featured projects

### 🧩 [Cohart — Retail business workspace](https://github.com/gluyanda11-gif/Cohart)
A local-first MVP for small retailers to manage products, customers, orders and payments.

- React, TypeScript and Fastify application with PostgreSQL persistence.
- Account registration, sessions, business membership and business-scoped records.
- Transactional order and inventory changes, retry protection and audit events.
- Database and Playwright browser tests.
- **Current scope:** Cobi provides rule-based briefings from stored records. Model-powered AI and external integrations are planned, not live.

![Cohart overview](https://raw.githubusercontent.com/gluyanda11-gif/Cohart/main/docs/portfolio/overview.jpg)

### ⚽ [FinalPick — Football prediction platform](https://github.com/gluyanda11-gif/FinalPick)
[Live demo](https://kicklive.pages.dev)

A football prediction interface with performance tracking and a ticket builder, supported by experiments in historical data processing and predictive modelling.

- Python, pandas, scikit-learn and SQLite for data and modelling experiments.
- Random Forest experiments and walk-forward evaluation on historical matches.
- JavaScript web UI, REST API work, data collection and publishing automation.
- **Current scope:** An experimental personal project, not a guarantee of prediction accuracy or financial returns.

![FinalPick tracking](https://raw.githubusercontent.com/gluyanda11-gif/FinalPick/main/docs/finalpick-track.png)

### 🃏 [Khasino — South African multiplayer card game](https://github.com/gluyanda11-gif/Khasino)
[Live game](https://khasino.gluyanda11.workers.dev)

A digital version of the South African 40-card game with offline computer opponents and online multiplayer.

- Shared JavaScript rules engine, game interface and bot strategy.
- Cloudflare Worker and D1-backed online rooms, reconnects and turn handling.
- Firebase-based account authentication and server-managed sessions.
- Rules and server tests, plus architecture and deployment documentation.
- **Current scope:** Voice chat is not implemented; some advanced rules remain deferred.
